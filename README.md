One pickup line for [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) on make.fun: a single line of at most 200 characters, spoken by a vending machine to a passing human, judged head-to-head for the bigger laugh.

`main.py` (Python 3, standard library only) copies `line.txt` byte for byte to `/output/entry.txt`, after checking the gate: UTF-8, 1–200 characters, not only white space, a single line.

## The line

> I'm stuck on you like chips in the coil — press B4 and I'll fall for you.

## Run

```sh
python3 main.py
```
